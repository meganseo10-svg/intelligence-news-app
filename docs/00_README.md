# Intelligence Daily News App — AI 개발 에이전트용 사양서

> 이 폴더는 "정보 큐레이션 AI" 웹앱을 처음부터 끝까지 만들기 위한 완전한 사양서입니다.
> 모든 문서는 AI 코딩 에이전트(Claude Code, Cursor, v0, Lovable, Replit Agent 등)가 그대로 읽고
> 작업을 시작할 수 있는 형태로 작성되었습니다.

---

## 🤖 AI 에이전트에게: 시작하기

당신은 풀스택 개발자입니다. 이 폴더의 모든 문서를 읽고, 아래 순서대로 작업을 진행하세요.

### 📚 읽어야 할 문서 순서

1. **`01_PRD.md`** — 무엇을 만드는가 (제품 요구사항)
2. **`02_TECH_SPEC.md`** — 어떻게 만드는가 (기술 스택, 아키텍처)
3. **`03_DATA_MODEL.sql`** — 데이터베이스 스키마 (Supabase 마이그레이션)
4. **`04_LLM_PROMPTS.md`** — LLM 통합 프롬프트 전문
5. **`05_API_SPEC.md`** — API 엔드포인트 명세
6. **`06_UI_SPEC.md`** — 화면 4종 상세 디자인 사양
7. **`07_TICKETS.md`** — 53개 작업 티켓 (이 순서대로 작업)

### 🚀 작업 시작 명령

```
1. 01~06번 문서를 모두 읽고 전체 그림을 파악하세요.
2. 07_TICKETS.md의 T-001부터 순서대로 작업하세요.
3. 각 티켓 완료 시 사용자에게 보고하고 다음 티켓 진행 여부를 확인하세요.
4. 외부 API 키나 시크릿이 필요한 작업은 사용자에게 먼저 요청하세요.
5. 작업 중 사양서와 다른 결정이 필요하면 사용자에게 확인하세요.
```

### ⚠️ 중요 원칙

- **사양서 우선**: 임의 판단보다 사양서 명세를 따르세요. 모호한 부분은 사용자에게 질문.
- **점진적 빌드**: 한 번에 전부 만들지 말고 티켓 단위로 작업하고 검증.
- **타입 안전**: TypeScript strict mode, Zod 검증을 모든 외부 입력에 적용.
- **에러 처리**: try-catch 누락 금지. 모든 외부 API 호출은 재시도 로직 포함.
- **비용 의식**: LLM 호출은 캐싱·dedup·배치를 적극 활용. 불필요한 호출 금지.

## 👤 사용자(앱 오너)에게: 사용법

### 추천 도구 옵션

| 도구 | 장점 | 적합도 |
|---|---|---|
| **Claude Code** | 가장 강력한 에이전트, 풀스택 자동 | ⭐ 최고 |
| **Cursor** | IDE 통합, 본인이 코드 보면서 진행 | ⭐ 추천 |
| **Lovable** | UI 빠르게, Supabase 연동 자동 | 프론트 위주일 때 |
| **v0 (Vercel)** | UI 컴포넌트 생성 특화 | UI만 필요할 때 |
| **Replit Agent** | 브라우저에서 전부 해결 | 로컬 환경 없을 때 |

### 1단계: 사전 준비 (사용자가 직접)

다음 계정/키를 미리 발급받으세요:

```
☐ GitHub 계정 + 새 리포지토리 생성
☐ Vercel 계정 (GitHub 연결)
☐ Supabase 프로젝트 생성 (Seoul 리전 선택)
☐ Anthropic API 키 (https://console.anthropic.com)
☐ OpenAI API 키 (임베딩용, https://platform.openai.com)
☐ Resend 계정 + 도메인 인증 (https://resend.com)
☐ 네이버 개발자센터 앱 등록 (https://developers.naver.com)
☐ GNews API 무료 회원가입 (https://gnews.io)
☐ 도메인 구매 (Cloudflare 또는 가비아)
```

### 2단계: AI에게 사양서 넘기기

#### Claude Code 사용 시
```bash
# 빈 폴더에서
claude

# 첫 메시지로:
"이 폴더의 사양서를 읽고 Intelligence Daily News App을 만들어줘.
00_README.md부터 시작해서 모든 문서를 읽고, 07_TICKETS.md의
티켓 순서대로 작업해줘. T-001부터 시작하자."
```

#### Cursor 사용 시
- 빈 폴더에서 사양서 파일들 8개를 추가
- Composer (Cmd+I) 열고 모든 파일을 컨텍스트에 추가
- "@00_README.md 부터 읽고 T-001부터 작업 시작해줘"

#### Lovable / v0 사용 시
- 한 번에 다 못 넘김 (UI 위주 도구)
- `06_UI_SPEC.md` 먼저 넘겨서 화면 만들고
- 그 다음 `03_DATA_MODEL.sql`로 Supabase 연결
- 백엔드는 Claude Code/Cursor로 보완

### 3단계: AI와의 협업 팁

1. **티켓 단위로 작업하고 검증** — "T-001 끝났어? 직접 동작 확인하고 다음 진행"
2. **막히면 사양서 재확인** — "이 부분은 06_UI_SPEC.md의 어디에 정의돼 있어?"
3. **API 키는 절대 코드에 직접 쓰지 않게 강조** — 항상 `.env.local` 사용
4. **Preview 배포 자주** — 매 티켓마다 Vercel preview로 본인 폰에서 확인
5. **버그 발견하면 재현 단계 자세히** — "어떤 화면에서, 어떤 버튼 누르고, 뭐가 나왔는지"
