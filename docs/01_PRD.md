# 01. Product Requirements Document (PRD)

## 1. 제품 개요

### 1.1 한 줄 정의
**"사용자가 입력한 업계·경쟁사·제품 키워드에 맞춰 국내·해외 뉴스를 매일 자동 수집·번역·요약하고, 사용자 회사 관점의 비즈니스 시사점을 생성해 다양한 채널로 배달하는 B2B 인텔리전스 서비스"**

### 1.2 문제 정의
- 마케팅·영업·기획 담당자는 매일 경쟁사·시장 동향을 파악해야 함
- 현재는 구글 알리미 + 수동 정리로 30분~2시간/일 소요
- 해외 뉴스는 영어 장벽으로 활용도 낮음
- 단순 뉴스 나열만으로는 "그래서 우리는 뭘 해야 하나?"가 빠짐

### 1.3 솔루션
- 사용자가 회사 프로필과 키워드를 등록하면
- 매일 새벽 자동으로 국내·해외 뉴스 수집
- AI가 번역·요약·중복제거·시사점 생성
- 사용자가 원하는 시간·채널로 배달
- 인앱에서 카테고리별 정리 + 공유·저장 기능

### 1.4 차별점
- **개인화된 시사점**: 단순 요약이 아니라 "내 회사의 영업 기회/타겟 고객/리스크"까지
- **글로벌 커버리지**: 한국어/영어 동시 수집 + 자동 번역
- **다채널 배달**: 이메일/Slack/Discord/인앱 동시 지원
- **공유 우선**: 영업·팀 협업을 위한 공유 링크·다이제스트 기능

---

## 2. 타겟 사용자

### 2.1 1차 페르소나
- **김부장 (B2B 영업·마케팅 팀장)**: 경쟁사 동향 모니터링 필수
- **이대리 (스타트업 PM/기획자)**: 시장 트렌드 파악, 투자자 대응 자료
- **박팀장 (대기업 신사업 담당)**: 산업 트렌드 리포팅

### 2.2 사용 시나리오
1. **아침 출근길**: 메일 또는 카톡으로 받은 다이제스트 5분 훑기
2. **9시 회의 직전**: 앱에서 카테고리별로 필요한 부분 빠르게 확인
3. **자료 준비 중**: 관련 뉴스 검색 → 공유 링크 생성 → 동료에게 전달
4. **주말 정리**: 한 주 동안 저장한 뉴스 리뷰

---

## 3. 핵심 기능 (Must-Have, MVP 범위)

### 3.1 회원가입 + 비즈니스 프로필
- 이메일/Google/Kakao OAuth 로그인
- 회사명, 업종, 회사 규모, 주력 제품·서비스 입력
- 타임존 자동 감지

### 3.2 키워드 관리
- 4개 카테고리: 경쟁사 / 업계 동향 / 제품·기술 / 일반
- 카테고리별 키워드 등록 (최대 30개)
- AI 추천 키워드 (프로필 기반 자동 제안)

### 3.3 뉴스 수집 (자동, 매일 새벽)
- 국내: 네이버 검색 API
- 해외: GNews API + RSS 피드 (Reuters, TechCrunch, Bloomberg 등)
- 사용자별 키워드 × 소스 매트릭스로 수집

### 3.4 AI 처리
- 번역: 영문 → 한국어 (제목·요약)
- 요약: 본문 → 3~4문장
- 카테고리 분류: 사용자 키워드 그룹 매칭
- 시사점 생성: 사용자 회사 관점에서 영업 기회/타겟 고객/리스크
- 중복 제거: 임베딩 기반 의미 dedup + 클러스터링

### 3.5 데일리 피드 (인앱)
- 날짜별/카테고리별 보기
- 뉴스 카드: 제목, 요약, 시사점, 매체, 시간, 배지
- 액션: 원문 보기, 번역 토글, 복사, 공유, 저장
- 검색 + 필터

### 3.6 알림 설정
- 주기: 데일리 / 위클리 / 긴급만
- 시각: 프리셋(아침/출근/점심) 또는 직접 선택
- 채널: 인앱 / 이메일 / Slack / Discord (다중 선택)
- 표시 옵션: 자동 번역 ON/OFF, 원문 우선 표시, 중복 묶기

### 3.7 공유 기능
- 개별 뉴스 공유 (복사, 링크, 메일, 카톡, Slack, PDF, Notion)
- 다이제스트 공유 (전체 일자 묶음, 만료일 선택)
- 공개 링크 (로그인 없이 열람 가능)

### 3.8 저장 + 메모
- 북마크 + 본인 메모 추가
- 저장한 뉴스 별도 목록

---

## 4. 비기능 요구사항

### 4.1 성능
- 피드 페이지 로딩 < 1.5초
- AI 분석 1건 < 8초
- 일일 배치 완료 < 1시간 (사용자 100명 기준)

### 4.2 가용성
- 99% 이상 (베타 기준)
- Cron 실패 시 자동 재시도 + Sentry 알림

### 4.3 보안
- 모든 사용자 데이터는 RLS(Row Level Security)로 격리
- API 키·시크릿은 환경변수만 사용 (코드에 절대 금지)
- 공개 공유 링크는 만료일 + 토큰 검증

### 4.4 법무
- 뉴스 저작권 준수: 제목·요약(50자 이하)·링크만 노출, 본문 통째 복제 금지
- 개인정보처리방침, 이용약관 페이지 필수
- 외부 API ToS 준수 (네이버, GNews 등)

### 4.5 비용 목표
- 사용자 10~30명 베타: 월 7만원 이하
- 사용자 100명: 월 30만원 이하
- LLM 비용이 변동비 핵심 → 캐싱·dedup·배치로 최적화

---

## 5. Out of Scope (이번 MVP 제외)

다음은 베타 이후 단계로 미룸:

- 실시간(즉시) 알림 — 비용·복잡도 폭증
- 카카오 알림톡 — 사업자 인증 필요
- 모바일 네이티브 앱 (PWA로 시작)
- 팀 워크스페이스, 멤버 권한, 코멘트
- 결제·구독 (Stripe/토스)
- 분석 대시보드 (키워드 추이, 매체 분포 차트)
- API 공개 (외부 개발자용)
- 위클리/먼슬리 자동 리포트

---

## 6. 성공 지표 (KPI)

### 6.1 베타 단계 (출시 후 4주)
- 가입자 30명
- 일일 활성 사용자(DAU) 10명 이상
- 평균 세션 시간 3분 이상
- 메일 오픈율 40% 이상
- 시사점 만족도 (수동 인터뷰) 4/5 이상

### 6.2 정식 출시 단계 (출시 후 6개월)
- 가입자 1,000명
- 유료 전환율 3% 이상
- MRR ₩300만 이상
- NPS 30 이상

## 7. 위험 요소

| 위험 | 대응 |
|---|---|
| 네이버 API 한도 초과 | 빅카인즈 API 백업, 사용자 인당 키워드 한도 |
| GNews 무료 부족 | RSS 피드 충실, NewsData.io 유료 전환 |
| LLM 시사점 품질 낮음 | Few-shot 예시 + 사용자 프로필 디테일 강화 |
| 저작권 이슈 | 요약 50자 이하, 본문 통째 복제 절대 금지 |
| 베타 사용자 이탈 | 첫 7일간 매일 모니터링, 수동 인터뷰 |
